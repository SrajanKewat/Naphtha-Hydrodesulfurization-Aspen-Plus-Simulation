# Naphtha Hydrodesulfurization Process Simulation & Optimization

## Project Overview

This project focuses on the simulation, heat integration, sensitivity analysis, and techno-economic evaluation of a Naphtha Hydrodesulfurization (HDS) process using Aspen Plus.

The project was carried out as part of the Petroleum Refining & Process Design course at IIT Indore under the guidance of Dr. Rajan Singh.

## Process Simulation

The Naphtha HDS process was developed and simulated in Aspen Plus using:

- Aspen Plus V12
- Peng-Robinson EOS
- RStoic reactor
- Co-Mo/γ-Al₂O₃ catalyst
- RadFrac distillation
- Flash separation
- Amine absorption
- Hydrogen recycle

The process flowsheet includes feed preparation, preheating, hydrodesulfurization, cooling and flash separation, H₂S removal, product recovery, and hydrogen recycle.

## Heat Integration & Pinch Analysis

Heat integration and pinch analysis were performed using Aspen Energy Analyzer.

The analysis included:

- Process stream identification
- Hot and cold composite curves
- Pinch point analysis
- Minimum hot and cold utility requirements
- Heat exchanger network analysis
- Evaluation of heat-recovery opportunities

## Sensitivity Analysis

Four sensitivity studies were performed in Aspen Plus to investigate the effect of key operating parameters on process performance:

1. H₂ feed flow rate and reactor performance
2. Flash drum pressure and H₂ recovery/H₂S separation
3. Lean amine flow rate and H₂S removal/H₂ purity
4. Purge fraction and H₂ loss/compressor duty

## Techno-Economic Analysis

The economic performance of the simulated process was evaluated using Aspen Process Economic Analyzer (APEA).

The analysis included:

- Capital cost estimation
- Operating cost estimation
- Equipment cost analysis
- Utility cost analysis
- Raw material costs
- Product sales
- Profitability analysis
- Payback period
- Rate of return
